A small fix release.

- Client commands accept `--addr` as `host:port`, the same form `sapper server --addr` takes; `http://` is added when there is no scheme. Before, `--addr localhost:8089` failed with "unsupported protocol scheme".

Binaries for Linux, macOS and Windows are attached below, with `checksums.txt`. The container image is `ghcr.io/perruer/sapper:1.0.1`.

Full list: [CHANGELOG](https://github.com/Perruer/sapper/blob/main/CHANGELOG.md).
