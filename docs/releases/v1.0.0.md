The first release of **Sapper**, a maintained continuation of [Minefield](https://github.com/bitbomdev/minefield). Give it the SBOMs of your products and the vulnerability data you trust; it tells you which products each vulnerability reaches, how, and what to fix first.

### Highlights

- **`sapper report`**: every vulnerability with the products it reaches and a dependency path to each, ordered by CISA KEV, EPSS and reach. Table, Markdown or JSON.
- **KEV, EPSS and OpenVEX**: `sapper ingest kev|epss|vex`. Products that VEX clears are listed apart.
- **Correct matches**: SBOM relationships are read in the right direction, and OSV version ranges follow the spec (Go pseudo-versions, `introduced: 0`, PyPI/Maven version order). Records of one vulnerability are merged.
- **One static binary**: pure-Go SQLite, a database file by default, binaries for Linux, macOS and Windows, and `ghcr.io/perruer/sapper:1.0.0`.
- **Fast**: the whole Go database of osv.dev loads in seconds.
- **`sapper llm` with any OpenAI-compatible API**, including local models.

Full list of changes: [CHANGELOG.md](https://github.com/Perruer/sapper/blob/main/CHANGELOG.md). Binaries are attached below with `checksums.txt`.
